📦 Parcel System REST API

Welcome to the Parcel System API. Use the following endpoints:

Create Parcel

POST /api/parcels/

Create a new parcel in DRAFT status.

Get All Parcels

GET /api/parcels/

Retrieve all parcels.

Get Parcel by ID

GET /api/parcels/{id}

Retrieve a specific parcel.

Update Parcel

PUT /api/parcels/{id}

Update a parcel (only in DRAFT status).

Delete Parcel

DELETE /api/parcels/{id}

Delete a parcel (only in DRAFT status).

Push Status

POST /api/parcels/{id}/push

Move parcel through business process statuses.

Status Flow

DRAFT → VIEW_BY_TRANSPORTER → SENT → VIEW_BY_RECEIVER → COMPLETED

API Response Format

{
    "success": true,
    "message": "Operation message",
    "data": { ... }
}

Use Accept: application/json or Accept: application/xml headers.
